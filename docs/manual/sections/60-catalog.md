Flow ships a bootstrap set of doc-types — the documents a senior engineer or PM already recognizes. Bind them to skills as you build a flow.

| Doc-type | Maturity | Purpose |
|---|---|---|
| **spec** | stable | Intent before planning — the *what* and *why*, never the how. |
| **plan** | stable | The ordered steps that turn a spec into work. |
| **findings** | stable | What a review surfaced — issues, risks, what passed. |
| **decision-record** | stable | Why we chose X over Y, captured at the moment of choosing. |
| **spike-log** | stable | What was tried and what we learned on an end-to-end run. |
| **change-summary** | stable | What shipped — ready to drop straight into a PR description. |
