The Flow Manual

Flow is a pipeline-builder for AI work. You assemble a chain of skills; every step leaves behind a document a human can actually read — and resume from.

Git was for code. Flow is for the docs your agents leave behind. Assemble a flow → run it spike or step → inspect, edit, or fork from any checkpoint.
