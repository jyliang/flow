Git was for code. **Flow is for the docs AI agents produce.**

**Settled**{.badge .settled} · The interchange format between AI work steps should be the same artifacts humans already review at work — specs, plans, decision records, postmortems, RFCs.

Not graphs, not opaque agent state, not JSON traces. Documents a senior engineer or PM would recognize at a glance — markdown, or HTML when it deserves to be read. This is a 20-year-stable bet, because the artifacts predate AI.

**Settled**{.badge .settled} · Humans must be able to inspect, edit, and resume from any step in the pipeline.

Inspection without modification is theater. If a human can read a doc but not fix it and continue, the loop is closed and the human is decoration.
